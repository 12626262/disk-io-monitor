磁盘读写监控 - 免安装便携版
============================

这 3 个 exe 使用 Python 3.8 打包，兼容 64 位 Windows 7 / 8 / 10 / 11，
不需要在目标电脑上安装任何环境。

使用方法
--------
1. 把整个 bin 文件夹拷到目标电脑（放哪里都行）
2. 双击 开始监控.bat
3. 浏览器自动打开 http://127.0.0.1:8787/dashboard.html
4. 页面每 60 秒自动刷新；停止请双击 停止监控.bat

单实例说明
----------
同一时间只允许一个监控进程。如果监控已经在运行，再点 开始监控.bat
只会提示“已经在运行中”，不会重复启动。

开机自动启动（可选）
-------------------
双击 安装开机自启.bat，之后每次登录 Windows 会自动在后台采集。
取消：双击 卸载开机自启.bat。

文件说明
--------
collector.exe   采集器（后台统计各应用读写量，写到 data\disk_io.db）
serve.exe       仪表盘服务（每 60 秒重新生成页面，托管在 8787 端口）
report.exe      手动生成报告（输出 output\dashboard.html）
data\           数据库和日志（整个文件夹拷走，历史数据也跟着走）
output\         生成的仪表盘页面

注意事项
--------
- 仅支持 64 位 Windows 7 及以上（Win7 需 SP1，且建议打齐系统补丁）
- 数据从第一次启动开始累计，不会回溯历史
- 进程读写量是逻辑 I/O（含缓存），与物理磁盘计数略有差异，属正常
- 如果 8787 端口被占用，可用命令行运行 serve.exe --port 端口号 换端口
